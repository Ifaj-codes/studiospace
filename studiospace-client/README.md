# StudioSpace - Peer-to-Peer Creative Workspace

Live Website: [ekhane pore tomar Vercel link dibe]

## Features of this website:
* Users can easily explore creative studio spaces and book them.
* Registered hosts can add new studios with hourly rates and details.
* Hosts can manage, update, and delete their own studio listings.
* Fully responsive design for mobile, tablet, and desktop views.
* Secure data storage using MongoDB and fast UI with Next.js App Router.

## Tech Stack Used:
* Next.js (App Router)
* Tailwind CSS
* Express.js
* MongoDB Database
